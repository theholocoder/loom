# Loom drives the agents installed on the user's machine

Loom does not bundle or embed Pi or OpenCode. The Client runs the user's own installation (`pi --mode rpc`, `opencode serve`), which is already signed in to the user's model providers. Loom has no provider settings and stores no provider credentials: providers, API keys, subscriptions and the default model all come from the agent's own setup, and the composer's model picker lists the models the agent reports. We considered embedding Pi's SDK in Electron with a Loom-owned login UI and credential store, but that would duplicate each agent's login, store secrets in Loom and pin agent versions to Loom releases. The cost is that Loom depends on a supported agent version being installed and signed in, which it checks and warns about, as it does for `gh`/`glab` (ADR 0002).
