# Electron client instead of a web app with a local daemon

Loom's development work (agents, codebases, git, worktrees) must run on the developer's machine, which a browser tab cannot do. We considered a centrally served React web app talking to a local companion daemon over localhost, but its only advantage — updating for everyone at once — is lost as soon as every developer must also install and update a local process, and it adds browser-to-localhost security friction. So the client is a single Electron app (React UI + Node main process running agents and git). (The TypeScript team server this ADR also mentioned was dropped in ADR 0006.)
